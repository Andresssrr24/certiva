# Memoria del proyecto Certiva

## Branding aprobado por Bryan

Estado: APROBADO. Bryan eligió la versión v5 con «perfecto ese sería el branding». Esta decisión reemplaza las exploraciones de nombres, el logo C inicial, la paleta celeste inicial y las aplicaciones v1–v4.

### Referencia visual canónica

`docs/marketing/brand/certiva-aplicaciones-azul-v5.png`

Usar esa lámina como referencia principal para futuras piezas, presentaciones, web e interfaz. No volver a versiones anteriores por defecto.

### Identidad

- Nombre: **Certiva**; firma gráfica en minúsculas: **certiva**.
- Descriptor aprobado: **Tu aliado contra el fraude**.
- Frase de campaña: **Antes de responder, verifica**.
- Símbolo: **03 · Enlace original**, dos piezas curvas entrelazadas; blanca arriba a la izquierda, azul abajo a la derecha; abertura central y contenedor blanco de esquinas redondeadas.
- No confundir con E3 de la segunda ronda de exploraciones. La elección se hizo con una captura del 03 original.
- Firma compacta: ícono y palabra próximos, alineados ópticamente. Evitar la separación amplia del primer manual.
- Lettering geométrico en minúsculas, robusto, de carácter premium, tomando como referencia la v5. Arial del PDF v1 no es la dirección aprobada para el wordmark.

### Color y acabado

- Azul base definido: **#205094**, RGB **32, 80, 148**.
- Blanco: **#FFFFFF**.
- Azul tomado de la captura de Caja de Ahorros aportada por Bryan; no es una especificación del manual oficial del banco verificada externamente.
- Aplicar el HEX exacto en elementos planos y código. La lámina generada es una referencia visual con iluminación, no una garantía de coincidencia de cada píxel.
- Glow sutil solo en bordes y detalles. Mantener fondos y superficies de marca uniformes; evitar lavados amplios de luz o degradados que cambien el azul base.
- Acabado premium: cerámica blanca, volumen suave, reflejos controlados y composición limpia.

### Aplicaciones y límites

- La lámina aprobada muestra firma principal, app, web, tarjeta, ícono y presentación.
- Son mockups de marca, no prueba de una aplicación móvil o web publicada.
- No incorporar el logo de Caja de Ahorros ni afirmar un aval, asociación comercial o producto oficial por usar su paleta.
- El PNG v5 está disponible. El master vectorial, la fuente exacta del lettering y las exportaciones finales aún no están producidos.
- `output/pdf/Certiva-Brand-Book-v1.pdf` es histórico: no representa la tipografía, el descriptor ni la paleta final. Actualizarlo con esta memoria cuando se solicite una nueva edición.

## Alcance de producto confirmado por Bryan

- USDT y wallets cripto quedan fuera del alcance; no son requisitos.
- La dirección actual es banca, con Caja de Ahorros como referencia: SDK móvil, consola de fraude y modelo comercial para que el banco lo ofrezca o comercialice a sus clientes.
- Propuesta vigente: `docs/PRODUCTO-BANCA-Y-MODELO-COMERCIAL.md`. Precios, piloto y modalidad de cobro son hipótesis propuestas, no decisiones comerciales aprobadas ni acuerdo con el banco.
