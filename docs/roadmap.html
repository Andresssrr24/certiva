Quién hace qué

Tres roles cubren el núcleo. La cuarta persona, si existe, va al Android o a Ovnicom, nunca a las dos cosas.

RolDueño deSu entregable del día
ModelosIntegración del SDK: VisionPsy, Qwen3, transcripción, RAG, pares, registro de rendimientoEl pipeline completo corriendo sin red
AppElectron y la interfaz, el puente IPC, el modo banco, la grabación del videoLa demo que se ve en el video
DatosGenerador sintético, reglas deterministas, script de evaluación, READMELa evidencia reproducible
ExtraAndroid con Expo, o el módulo Ovnicom si tiene perfil de infraestructuraUna captura leída en un teléfono real

Todos son decisiones de equipo que se toman juntos y se anotan en el README.

Stack y arquitectura, decididos el 10 a las 08:45

Un solo proceso por máquina es dueño de los modelos: dos procesos de QVAC en la misma máquina se bloquean en el worker compartido. Todo lo que decide es JavaScript puro que corre donde sea.

Lo que se fija esta noche

Estos dos esquemas y esta lista de reglas son el contrato entre los tres roles. La gramática del SDK obliga al modelo a respetarlos, así que el resto del código puede confiar en la forma.

Reglas deterministas v1

ReglaEvidencia que produce
Dominio parecido a uno oficialDistancia de edición o token de marca dentro de un dominio que no está en la lista oficial
Acortador, IP literal o punycode en el enlaceEl enlace tal cual y el motivo
Número fuera de la lista oficialEl número y que no coincide con los canales del banco
Pide clave, PIN, código de verificación o datos de tarjetaLa frase exacta del mensaje
Presión de tiempo o amenaza de bloqueoLa frase exacta
Pago a cuenta de terceros o por Yappy a un particularEl monto y el destino

Mensaje entre pares

{ "v": 1, "tipo": "dominio" | "numero" | "plantilla", "hash": "sha256 del indicador normalizado",
  "veredicto": "fraude", "ts": 1757548800, "origen": "id anónimo del nodo" }

Nunca viaja el mensaje ni la captura. Solo el hash, el tipo y el veredicto.

Cargar VisionPsy y extraer con esquema

import { loadModel, completion, VISIONPSY_NANO_460M_MULTIMODAL_Q8_0,
         MMPROJ_VISIONPSY_NANO_460M_MULTIMODAL_Q8_0 } from '@qvac/sdk'

const vision = await loadModel({
  modelSrc: VISIONPSY_NANO_460M_MULTIMODAL_Q8_0,
  modelConfig: { ctx_size: 4096, device: 'gpu',
    projectionModelSrc: MMPROJ_VISIONPSY_NANO_460M_MULTIMODAL_Q8_0,
    image_no_upscale: 'on' }
})

const run = completion({
  modelId: vision, stream: true,
  history: [{ role: 'user', content: PROMPT_CAPTURA, attachments: [{ path: rutaPng }] }],
  responseFormat: { type: 'json_schema', json_schema: { name: 'captura', schema: ESQUEMA_CAPTURA } }
})
const t0 = Date.now(); let ttft = null
for await (const ev of run.events) { if (ev.type === 'contentDelta' && ttft === null) ttft = Date.now() - t0 }
const captura = JSON.parse((await run.final).contentText)

npm i -D electron
